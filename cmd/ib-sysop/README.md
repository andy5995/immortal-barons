# ib-sysop: the sysop panel

A desktop window for a sysop or League Coordinator: a board's league state and
the game's maintenance commands. It is its own Go module, so the game's
`go.mod` never carries its GUI toolkit, [Gio](https://gioui.org/).

How to build and use it: [Sysop Panel](../../docs/sysop-panel.md).
