# Подставить

Подставить обманывает цель и одного из её партнёров по договору, и каждый
верит, что другой объявил ему войну. Все договоры между ними
расторгаются. Если у цели есть Полный оборонительный союз, выбирается этот
партнёр. Вашему агенту нужно обмануть обе державы, поэтому Подставить
проваливается чаще других простых операций. Используйте её, чтобы разрушить
оборонительный союз перед нападением на врага.
