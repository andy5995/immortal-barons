# Expose Enemy Ops

Expose Enemy Ops turns a bribed agent against the service that employs it. For
the next day, nine in ten of that realm's covert operations against you are
caught before they do anything.

It works against ONE realm — the realm the agent is inside — so the menu lists
only the realms you have already bribed. Bribery comes first; without an agent
on your payroll there is nothing to expose. A tenth of that realm's attempts
still get through.

It costs no agent and takes no once-per-turn slot, so you may run it as often as
you can pay for it. Anything the shield turns aside counts as a caught agent, so
on top of blocking the damage you are told which realm sent it.
