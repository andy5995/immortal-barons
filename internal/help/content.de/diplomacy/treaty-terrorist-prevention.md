# Terrorabwehr

Terrorabwehr verbindet die Geheimdienste der beiden Reiche. Gegen
Terroroperationen von einem anderen Planeten helfen die Agenten Ihres
Partners, Sie zu verteidigen.

Vor verdeckten Operationen auf Ihrem eigenen Planeten schützt es Sie
nicht. Dort zählt das Spiel die Agenten Ihres Partners gegen Ihre eigenen
Operationen, so dass diese seltener gelingen.
