# Ödlandregionen

Ödland ist eine Region, die ein nuklearer oder chemischer Schlag verwüstet
hat. Sie können es weder kaufen noch aufgeben; ein Feind schenkt es Ihnen.

Ödland bleibt in Ihren Büchern. Es zählt zu Ihrem Gebiet, kostet denselben
Unterhalt wie jede andere Region und bringt Ihnen nichts. Ein Reich, das
mehrere Schläge einsteckt und sie hinnimmt, zahlt am Ende für Regionen, die
nichts leisten.

Die Beseitigung heißt Dekontamination und wird bei der Wartung angeboten,
sobald Sie welches halten. Es gelten zwei Grenzen:

- Sie können **je Zug ein Fünftel Ihres Ödlands** reinigen, nie weniger als
  **10 Regionen** und nie mehr, als Sie tatsächlich halten. Eine große
  Verwüstung braucht mehrere Züge, wie reich Sie auch sind.
- Jede gereinigte Region kostet **die Hälfte des laufenden Preises für neue
  Regionen**. Eine hohe Technologiestufe senkt das weiter, bis auf ein
  Viertel.

Wer einen Teil der Rechnung zahlt, reinigt einen Teil des Ödlands.

Gereinigte Regionen haben keine Art, bis Sie ihnen eine geben. Sie werden
gebeten, sie auf die Regionsarten aufzuteilen, genau wie eroberte Regionen.

Strategie: Reinigen Sie früh. Sie zahlen jeden Zug Unterhalt für Ödland, und
Sie können jeden Zug nur einen Teil davon reinigen.
