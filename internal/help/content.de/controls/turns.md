# Züge und Schutz

Sie erhalten jeden Tag eine feste Anzahl von Zügen. Wenn Sie alle verbraucht
haben, kommen Sie am nächsten Tag für weitere zurück.

Der Tag wechselt um Mitternacht auf dem Rechner, der das Spiel betreibt. Das
ist nicht überall dann Mitternacht, wo Sie sind, daher zeigt das
Eingangsmenü die spieleigene Zeit und wie viel vom Tag noch bleibt.

Jede Zeit auf dem Bildschirm nennt ihre Uhr. Zeiten stehen anfangs in UTC,
worauf sich jeder Planet einer Liga verständigt, und die Einstellungen
zeigen sie auf Wunsch auf einer anderen Uhr: der dieses Boards oder einer
Zeitzone, die Sie aus einer Liste wählen.  Der Countdown zum neuen Tag ist
gleich lang, welche Sie auch wählen.

Neue Spieler erhalten Neureich-Schutz: eine Anzahl von Zügen, in denen Sie
weder angreifen noch angegriffen werden können. Das gibt Ihnen Zeit, sich
aufzubauen.

Ein Reich, das noch unter Schutz steht, zeigt seinen Buchstaben in eckigen
Klammern in den Listen der Reiche - `[C]`, wo jedes andere Reich `(C)` zeigt
-, so dass Sie sehen, wer noch nicht angegriffen werden kann.
