# Handelsmarkt bombardieren

Handelsmarkt bombardieren ist eine interplanetare Operation im Menü
Spezialoperationen. Sie zerstört einen kleinen Teil von allem, was auf dem
Handelsmarkt eines anderen Planeten angeboten wird. Das Gold, auf das die
Verkäufer dort warten, wird nicht berührt. Die meisten Angriffe werden
abgewehrt, bevor sie ihn erreichen, und bewirken nichts.
