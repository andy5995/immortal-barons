# Demoralisera trupper

Demoralisera trupper sänker målets militära moral. Låg moral försvagar deras
armé i strid och kan orsaka desertering.

Din agent når dem bara vid daglig underhåll, så skicka en dagen innan
striden du vill att den ska påverka, inte samma drag som den.
